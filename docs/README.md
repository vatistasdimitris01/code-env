# Documentation

This directory stores durable knowledge for every app and project in the workspace.

## Sections

- `architecture/`: System design notes, diagrams, technical decisions, and integration plans.
- `operations/`: Runbooks, deployment steps, monitoring notes, and maintenance procedures.

## Documentation rules

- Write docs close to the decision or workflow they explain.
- Include dates for decisions that may change over time.
- Link related apps, packages, issues, and pull requests when available.
